# ehime-kokubunsai-hp-poc

令和10年度 国民文化祭・全国障害者芸術・文化祭 愛媛大会（仮）の公式ホームページPoC。

## Versioning

- **v1**: 2026-04-26〜27に作成した静的HTMLモックの保存版。
- v1の固定点は `v1-frozen` ブランチで保持する。
- 今後の改修は `main` で行い、v1固定版は変更しない。

## v1 scope

- 静的 HTML / CSS / JavaScript
- 公式HP全体を想定したページ群
- ホームページ基本構成資料
- 仕様書・生成スクリプト
- 画像アセット

> このリポジトリは非公開PoCとして管理する。
