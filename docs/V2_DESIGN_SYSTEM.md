# v2の共通設計とD2の再設計

## 今回の判断

2.0.0-alpha.2の旧A・B案は、v1と同じ「大きな写真とコピー、紹介、カード一覧」という流れを引き継いでいた。
2026-10-01の比較で刷新の要件を満たさないと指摘され、旧A案への暫定推奨を撤回した。
2.0.0-alpha.3では、配色の比較から、構成と体験の比較へ戻した。
両案は未選定である。

## 2つの方向

| 項目 | 新A案：文化の群島 | 新B案：参加型ポスター |
| --- | --- | --- |
| 体験の起点 | 気になる文化を選ぶ | 観る・つくる・ともに楽しむ目的を選ぶ |
| 最初の構図 | 大きな文字と、群島のように配置した複数の写真 | 大きな文字を中心にしたポスターと、3つの参加目的 |
| 写真の役割 | 文化の選択に応じて主写真と説明を変える | 参加目的に応じて写真・言葉・案内先を変える |
| 読む流れ | 文化の選択、暮らしと文化、文化別索引、自分の参加、お知らせ | 参加目的の選択、大会の考え方、参加方法の索引、包摂性、お知らせ |
| 索引 | ジャンル別の大きな文字と写真 | 参加目的別の大きな文字と説明 |
| 主な色 | 濃い海の色、白、淡い黄緑 | 濃い青、黄、朱色、紙のような白 |
| 共通の実用性 | 常設の検索入口、重要情報、参加支援、資料 | A案と同じ目的を異なる構成で扱う |

「群島」は多様な表現のつながりを表す比喩であり、実際の地図ではない。
試作の線画マークも大会の正式ロゴではない。
写真は既存のイメージ素材を使用し、実際の大会写真として扱わない。
愛媛の固有性を深める撮影・編集・取材は後続工程で必要となる。

## トークンと書体

色、余白、書体、反応の時間を `design-lab/tokens.json` に集約する。
`tokens.css` は生成物である。
新トップの構成は `concepts.css`、下層の共通部品は `theme.css` で管理する。
現時点では画面構成が異なる2案を比較しており、全ページ用の部品体系は確定していない。

| A案の地の色 | #edf2e9 |
| A案の差し色 | #d6ed9b |
| B案の青 | #172b72 |

元書体のGoogle FontsコミットとSHA-256を固定している。
OFL全文と出典を同梱し、サブセットの内部書体名は変更している。
文字を追加した場合は、生成スクリプトでサブセットを作り直す。

## 選択操作

A案は工芸・舞台・文学・食文化を選び、主写真、説明、ジャンル検索、掲載例のリンクを同時に更新する。
B案は観る・つくる・ともにを選び、写真、見出し、説明、目的に対応するリンクを同時に更新する。
選択はURLに記録し、再読込と履歴移動で復元する。
未定義の値は既定の案内へ戻る。
選択時にフォーカスを移さず、選択状態と更新の通知を提供する。
自動再生や、自動で変わる写真は使用しない。

JavaScriptが無効でも、文化別の4入口と参加目的別の3入口は通常のリンクとして残る。
検索、重要なお知らせ、参加支援、資料への到達は写真の操作に依存しない。
小画面ではメニューに加え、常設の検索入口と重要情報へのリンクを置く。

## 動きと性能

写真やボタンの短い反応を使い、入口の選択で画面の内容を変える。
スクロールや読み込みを待たせるイントロは置かない。
動きを低減する設定ではトランジションと写真の回転を停止する。
高コントラスト設定では選択状態を輪郭で示す。
これらの実ブラウザーによる確認は未完了である。

写真は480px、960px、1440pxのWebPを配信する。
主要写真には優先指定を付け、その他の写真は遅延読込にする。
書体は同梱WOFF2とし、font-display: swapで本文の表示を待たせない。
素材容量は測定できるが、実際の読み込み時間や操作遅延の合格証拠とは区別する。
全素材を同梱するreview.htmlも、通常配信版の性能測定には使わない。

## 確認の順序

最初の画面の構図、下へ進んだときの構成、選択操作と行き先をv1と比較する。
次に390px、320px、PC幅で表現と実用性を確認する。
方向を決めた後にD3でトップへ適用し、D4で下層ページを同じ考え方から再設計する。
現在の下層ページは操作部品の試作であり、トップと同じ深さの再設計はまだ行っていない。

## 再生成

```bash
python scripts/build_v2_lab.py
python scripts/build_v2_assets.py
python scripts/build_v2_review.py
python scripts/qa_v2_lab.py
npm install --prefix .cache/v2-qa jsdom@30.1.1
NODE_PATH="$PWD/.cache/v2-qa/node_modules" node scripts/qa_v2_interactions.cjs
python scripts/render_v2_layouts.py --all
```

WeasyPrintの画像は静的な配置の参考資料であり、実ブラウザーのスクリーンショットではない。
JavaScriptの選択操作や、その実行後の状態を確認する資料にも使わない。
今回の検証結果と残る確認は `V2_D2_RESET_REVIEW.md` に記録する。
