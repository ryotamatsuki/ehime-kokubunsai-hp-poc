# v2の共通設計とD2試作

## D2の成果

D2では共通部品と代表ページの試作を作成した。
A案を暫定の既定案とし、B案を比較対象として保持する。
色や文字組の確定は、比較ファイルを実際のブラウザーで評価してから行う。

| 試作 | ファイル | 確認する内容 |
| --- | --- | --- |
| 比較の入口 | `design-lab/index.html` | 2案の方向と代表ページへの導線 |
| A案 | `design-lab/home-a.html` | 写真と余白で文化を伝える構成 |
| B案 | `design-lab/home-b.html` | 文字と色で祝祭感を伝える構成 |
| 検索 | `design-lab/event-search.html` | 絞り込み、件数、0件、リセット |
| 詳細 | `design-lab/event-detail.html` | 日時、会場、料金、申込、参加支援 |
| 資料 | `design-lab/documents.html` | 読むための幅、ページ内目次、資料の状態 |
| 部品 | `design-lab/components.html` | 入力、エラー、タグ、長い名称、フォーカス |
| 単独で開ける比較ファイル | `design-lab/review.html` | ページと表示幅を切り替えて操作する |

比較ファイルには写真、書体、CSS、JavaScriptを同梱した。
インターネット接続を必要としない。
通常の各HTMLにも本文とリンクを置き、JavaScriptが無効でも情報を読める構造にした。

## 2つの表現

| 項目 | A案 | B案 |
| --- | --- | --- |
| 狙い | 文化を担う人と作品への関心を育てる | 大会への参加感と祝祭感を伝える |
| 紙面の表情 | 文化誌、展覧会の図録を意識した写真と余白 | 文化祭のポスターを意識した文字と色 |
| 地の色 | 温かな白 | 薄い土色 |
| 主な色 | 深い緑と温かな朱色 | 土色と濃い緑 |
| 写真 | 主写真に工芸の場面を重ねる | 参加風景に作品鑑賞の場面を重ねる |
| 読む順序 | 大会への関心から、探す、参加する、支援を確認する | 大会の参加感から、探す、支援を確認する |
| 共通化する部分 | 検索、資料、情報の状態、操作部品 | A案と同じ構造を使用する |

愛媛の固有性は、工芸、舞台、地域の風景、文化を楽しむ人の編集を通じて表す。
画像の選択とコピーの組み合わせを検証する段階であり、実際の大会写真への差し替えは後続工程の課題とする。
既存画像はイメージとして明示し、実際の会場や開催風景と誤認される表示を避ける。

## 書体と文字組

| 用途 | 書体 | 方針 |
| --- | --- | --- |
| 日本語 | Zen Kaku Gothic Newを基にした同梱サブセット | 本文400、見出し700を基本にする |
| 英字と数字 | Manropeを基にした同梱サブセット | 小見出し、年、件数に使用する |
| 本文 | 16px、行高1.9を基本にする | 文章を読む領域は最大42rem |
| 大見出し | 画面幅に応じて可変 | 文字を固定高さの箱で切らない |
| 補助情報 | 主本文より小さくする | 色の濃さと文脈で区別する |
| 長い名称 | 折り返して全体を表示する | 正式名称の省略を共通ルールにしない |

配布するサブセットの内部書体名は `Ehime Lab Sans` と `Ehime Lab Latin` に変更した。
原書体のOFL全文と出典を同梱している。
元ファイルはGoogle Fontsのコミットを固定し、SHA-256を照合してから加工する。

現在のv1とD2に現れる文字を集めてサブセットを作成する。
新しく追加された未収録文字はシステム書体で表示される。
本文が増えた場合は、画像と書体の生成スクリプトでサブセットを再作成する。

## 色と配置

色、余白、書体、動きの基準値は `design-lab/tokens.json` に集約した。
`tokens.css` は生成物であり、変更はJSONを起点に行う。
画面構成は最大1280pxの領域を基本とし、読み物の幅は別に制限する。

| 値 | A案の設定 | 用途 |
| --- | --- | --- |
| page | `#f7f4ed` | 地の色 |
| ink | `#173b35` | 主な文字、主要操作 |
| muted | `#52645f` | 注記、補助情報 |
| accent | `#b8492d` | 小見出し、注意の目印 |
| wash | `#e6ece4` | セクションの区切り |
| focus | `#0069ba` | キーボードの現在位置 |
| control-line | `#6c8078` | 入力と操作部品の境界 |

余白は4px、8px、12px、16px、24px、32px、48px、64px、96pxを基準にする。
写真は、トップ、文化紹介、催しカードで役割に応じた比率を使う。
横長画像を各領域に収める際は `object-fit` と位置指定で構図を調整する。

## 操作と状態

操作部品は44px以上の高さを基本にする。
キーボードのフォーカスには3pxの輪郭を表示する。
スマートフォンのメニューは表示を開閉する構成とし、Escapeで閉じて起点にフォーカスを戻す。
JavaScriptが無効の場合は、ナビゲーションを表示したままにする。

検索ではキーワード、市町、ジャンル、参加の支援を組み合わせられる。
結果件数を読み上げに通知し、0件の場合には条件の変更とリセットを案内する。
URLの条件を復元し、無効な選択値は全件表示へ戻す。
催しの詳細では、選ばれた催しと画像、説明、地域、ジャンル、支援の表示を対応させる。

未確定情報は名称、日時、会場、料金、申込方法ごとに表示する。
資料が未公開の場合は「準備中」と表示し、ダウンロードできないリンクを作らない。
問い合わせ先や申込先の仮の連絡先は作らない。

## 動き

短い反応は140ms、写真の反応などは240msを基準にする。
この段階ではボタンと写真の小さな反応に限定した。
ページ遷移やスクロールの演出はD5で検証する。

`prefers-reduced-motion` ではスクロール補間、トランジション、ホバー時の移動を停止する。
動きを止めても、本文とリンクが欠落しない構造にする。

## 性能の準備

画像は480px、960px、1440pxのWebPを作り、表示幅に応じて配信する。
主要画像には優先指定を付け、下方の写真は遅延読込にする。
書体はWOFF2を同梱し、`font-display: swap` で本文の表示を待たせない。
外部の書体CDNやJavaScriptライブラリーは実行時に必要としない。

素材容量は測定済みだが、描画速度と操作の遅延は未測定である。
単独の比較ファイルは全素材を同梱するため、通常配信版の性能判定には使わない。

## 再生成

Python側の開発依存は `scripts/v2-dev-requirements.txt` に記録した。
操作ロジックの検査にはjsdom 30.1.1を使用した。
jsdomは試験用であり、ページの実行には必要ない。

```bash
python scripts/build_v2_lab.py
python scripts/build_v2_assets.py
python scripts/build_v2_review.py
python scripts/qa_v2_lab.py
npm install --prefix .cache/v2-qa jsdom@30.1.1
NODE_PATH="$PWD/.cache/v2-qa/node_modules" node scripts/qa_v2_interactions.cjs
python scripts/render_v2_layouts.py --all
```

最後のコマンドはWeasyPrintによる静的な配置の参考画像を作る。
ブラウザーのスクリーンショットとは区別して扱う。
