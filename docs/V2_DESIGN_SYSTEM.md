# v2の共通設計 — 愛媛を、ひらく。

対象は2.0.0-alpha.5、状態はfestival-content-reviewである。
旧A/B比較を終了し、一つの編集方針をトップと下層へ適用した。
この段階はv2.0の完成判定ではない。

## 内容から画面と操作を決める

トップは、舞台・鑑賞・交流・制作を含む文化祭全体の情景と、開催情報を起点にする。
工芸・文学・食文化・表現は、人の営みを描いた固有の生成画像と、場所・出典を持つ4章として扱う。
4章はこのPoCの入口であり、大会の全ジャンルや全開催地域を網羅する分類ではない。

「愛媛を、ひらく。」はPoCの提案コピーである。
大会の正式ロゴやキャッチフレーズとして表示しない。
大会名称・会期と個別催しの掲載状態は、この提案コピーから分離して明示する。

| 層 | 表現 | 次の行動 |
| --- | --- | --- |
| トップ | 文化祭全体の情景、藍の大見出し、独立した会期欄 | 文化の入口、常設の検索 |
| 文化の各章 | 地域、読み物、出典、各文化の生成画像 | 関連する催し、次の文化 |
| 工芸の絵付け | 白い器に重ねるSVGの線 | 任意の制作、取り消し、SVG保存 |
| 催しの案内 | 個別画像、確認済み／掲載例、日時・会場・料金・申込の状態 | 公式案内、文化帖への追加 |
| 文化帖 | 選択した文化で変わる表紙のしるし | 再訪、削除、SVG保存、通常配信版でリンク共有 |
| 資料・支援 | 静かな文字組、公開状態、一次出典 | 正式な情報・窓口へ移動 |

## トークン

`design-lab/tokens.json` を値の正とする。
ビルド時に `tokens.css` と `experience.css` の先頭の変数を同期する。
静的検査で内容とバージョンの不一致を検出する。
現在のページは `experience.css` のみを読み込む。
旧 `concepts.css`、`theme.css` は以前の試作の履歴であり、現在の部品体系ではない。

装飾の区切り線を、入力やフォーカスを認識するための境界として使わない。
写真上の文字は装飾的な英字に限定し、日時や操作などの重要情報を重ねない。

## 文字とグリッド

日本語はZen Kaku Gothic Newの400・700、英字と数字はManropeの200–800をサブセット化した。
CSSの別名はEhime SansとEhime Latin、書体内部名はEhime Lab SansとEhime Lab Latinである。
元書体のコミット・SHA-256・OFLを `assets/manifest.json` と同梱のライセンスに記録する。
表示する文字を追加した場合は `build_v2_assets.py` で再生成する。
`font-display: swap` と代替書体で本文を先に読めるようにする。

本文はPC20px、小画面18pxを基本とし、文化の本文は最大720pxで行間を確保する。
日時・料金・注記などの主要情報は16–18px、入力・操作は18px以上を基本にする。
トップの主見出しは1440px幅92px、390px幅46px、320px幅40pxとし、「全国へ。」の途中で改行しない。
小さな英字は視覚上の索引であり、日本語の本文や状態表示を置き換えない。

トップは横長の文化祭写真と7:5の情報欄、文化の入口は大小と位置を変えた2列グリッドを用いる。
文化の入口では位置と大きさを変え、重要情報や検索結果では規則的な行に戻す。
小画面では一列へ組み替え、文化の順序・本文・検索・保存操作を省略しない。

## 操作と復元

文化の紹介は普通のリンクで移動し、JavaScriptがなくても本文と出典を読める。
検索は日本語のAND検索と地域・文化・支援・情報状態の組合せで絞り込む。
条件はURLに記録し、戻る・進む、未定義の条件、0件、リセットを扱う。
JavaScriptがない場合はすべての催しを表示する。

文化帖は有効な催しIDだけを保存し、重複や未定義のIDを除く。
保存・削除は押下状態、件数、読み上げ用の通知を更新する。
削除後は次の項目または空の状態の入口へフォーカスを移す。
保存できない環境では状態を説明し、URLによる選択を保持する。
文化帖は予約・申込を意味しない。

工芸の絵付けは利用者が選んだときだけ線を描ける。
通常のページスクロールと競合しないよう、初期状態は描画モードを無効にする。
円・波・線のプリセットはキーボードでも選べる。
Escapeで描画モードを終了し、取り消し・消去・保存を提供する。
線は最大32本、1本の入力点は最大256点とし、保存したベクトルの形式を検証する。
砥部焼の実際の製作工程を再現したシミュレーターとして扱わない。

小画面のナビゲーションは開閉式で、検索入口を常設する。
Escapeはメニューを閉じ、開いたボタンへフォーカスを戻す。
モーダルではなく、ページ内のナビゲーションとして扱う。

## 動きと素材

短い色・輪郭の変化、保存の反応、任意の画像ホバーを使う。
イントロ、自動再生、スクロールの乗っ取り、常時の描画ループを置かない。
動きの低減設定ではアニメーション・トランジション・滑らかなスクロールを止める。
高コントラスト設定、フォーカス、印刷用の状態も定義する。
実ブラウザーでの各設定の表示はまだ確認できていない。

文化祭全体の主画像1点と全6催しの固有画像を新規生成し、480・960・1440pxのWebPに変換した。
旧生成画像2点と元画像も保持する。v1で使われる写真18点には54点の配信用WebPを追加した。
生成元、指示内容、AI表示、SHA-256は `V2_ART_DIRECTION.md` と `assets/art-manifest.json` に記録する。
文化の図形、絵付け、文化帖のしるしは編集可能なSVGで実装する。
通常配信版の容量概算と、全ページ同梱の `review.html` の容量は別に記録する。

## 適用と確認

`content.json` と固定版の本文から、labの128ページとサイトの127ルートを生成する。
ルート表は `experience-manifest.json` を正とし、実ルートでは相対リンクを変換する。
トップのv1互換アンカーは残す。
元114サイトページの本文を保持し、元トップの情報は全体案内へ再配置した。基本構成資料1件も同梱する。
`V2_CONTENT_INVENTORY.json` に移行先を記録し、固定版と現在版を `compare.html` で比較する。

再生成コマンドはREADME、検査結果と現在の限界は `V2_SELF_REVIEW.md` を参照する。
静的検査、jsdom、WeasyPrintを実ブラウザー・実機・読み上げの検証と区別する。
