# D2の実装と検証記録

この文書は2.0.0-alpha.2の旧試作の記録である。
2026-10-01に「v1とそんなに変わらない」という評価を受け、方向性の要件を満たさないと判定した。
旧A案への暫定推奨と、次節以降にある旧案の採用方針は撤回した。
現在の再設計と検証結果は `V2_SELF_REVIEW.md` を参照する。
次節以降の比較画面とコマンドはalpha.2時点の履歴であり、現在の提出物を説明するものではない。

## 今回の到達点

v2.0の共通設計と代表ページの試作を実装し、バージョンを2.0.0-alpha.2へ進めた。
トップはA案とB案を作り、検索、詳細、資料、共通部品で設計の展開を試した。
A案を暫定の既定案としている。

D2は実装した試作を比較できる段階まで到達した。
実ブラウザーで方向を評価する工程は残っている。
D3のトップへの適用と、v2.0の完成判定は今回の範囲に含めていない。

## 試作の使い方

`design-lab/review.html` を単独で開く。
上部のボタンでA案、B案、検索、詳細、資料、共通部品を切り替えられる。
表示幅は画面幅、390px、320pxから選べる。

検索では「砥部」や「松山市 文学」を入力し、条件の組合せを確認する。
存在しないキーワードを入力すると0件の表示になり、条件をリセットできる。
詳細は選択した催しに応じて表示を変える。

スマートフォンの詳細ページは、写真の次に日時、会場、料金、申込の情報を置き、その後に本文を読む順序とした。
資料が準備中の場合は、ダウンロードできないリンクを作らず状態を表示する。

## 確認できた結果

| 検査 | 結果 | 根拠 |
| --- | --- | --- |
| HTMLの構造と参照 | 7ページ PASS | `design-lab/qa/static-checks.json` |
| 色の組合せ | 16組 PASS、通常文字の最小比 4.745:1 | 同上 |
| 素材のハッシュ | 24ファイル PASS | 同上 |
| 検索、開閉、詳細、単独比較ファイルのロジック | 11ケース PASS | `design-lab/qa/interaction-checks.json` |
| A案の小画面向け主要素材 | 339,937 bytes、予算500,000 bytes以内 | `static-checks.json` |
| B案の小画面向け主要素材 | 330,193 bytes、予算500,000 bytes以内 | 同上 |
| 静的な配置の参考画像 | PC幅とスマホ幅を生成 | `design-lab/qa/layout-references.json` |

素材容量の条件は、320〜390 CSS px、DPR 1、主要写真2点を480wで選択した場合である。
HTML、CSS、JavaScript、全書体、ブランド画像を含めて算定した。
実際の通信量、描画時間、操作遅延の実測ではない。

操作の検査にはjsdomを使用した。
検索条件の復元、無効な選択値、0件からの復帰、メニューのEscape処理、詳細と選択した催しの対応、JavaScript無効時の本文を確認した。
DOM上のロジックを検査する方法であり、実機のキー入力や読み上げの確認とは区別する。

## 修正した点

- 画像の縦横サイズを元ファイルの実寸に合わせた。
- 主要ボタンの文字を途中で折り返さないようにした。
- 小画面の長い大会名とメニューボタンが並ぶための幅を調整した。
- スマートフォンの詳細ページで、基本情報が本文の後ろに埋もれない順序にした。
- 検索の市町とジャンルを小画面で並べ、入力欄の意味はラベルで示した。
- 不明な催しIDでは、HTMLの既定サンプルと同じ内容へ戻るようにした。

## 実ブラウザーで確認できていない内容

この会話のクラウドブラウザーでは、ローカル試作へのアクセスが制限された。
そのため、実ブラウザーの表示と操作を完了したという扱いにはしない。

WeasyPrint 70で作った画像は、静的な配置の参考資料である。
JavaScriptが動かない状態のナビゲーションを表示し、ブラウザーのCSS処理とも差がある。
この画像を、Chromiumの表示検証やスマートフォンの合格証拠に使わない。

次の確認が必要である。

- ChromiumとSafariでPC幅、390px、320px、200%拡大を確認する。
- 横にはみ出した内容、固定高さによる欠落、メニューの操作順を確認する。
- キーボードと読み上げで検索、詳細、資料の主要タスクを完了する。
- 動きの低減設定と高コントラスト設定を確認する。
- 通常配信版でLCP、CLS、入力時の応答を測定する。
- 初見の利用者と運用担当者が、必要な情報を探して更新できるか確認する。
