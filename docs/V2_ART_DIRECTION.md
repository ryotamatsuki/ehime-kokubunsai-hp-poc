# alpha.6の素材・内容・生成指示

文化祭全体を主景にし、舞台・鑑賞・交流・制作を複数の人と場所の関係として描く。
砥部焼は工芸の一分野として扱い、トップの代表題材にはしない。
人物の活動と文化の広がりを、横長の主画像と6催しの個別画像で伝える。

| 新規生成画像 | 題材 | 用途 |
| --- | --- | --- |
| `festival-hero.png` | 瀬戸内の海、多世代の鑑賞者、小さな舞台、作品、制作・交流 | トップ全体の主景 |
| `event-stage.png` | 海辺の舞台と音楽・舞踊・観客 | 瀬戸内文化ステージ（仮） |
| `event-craft.png` | 親子がことばと絵付けを楽しむ工房 | 砥部焼とことばの工房（仮） |
| `event-food.png` | 宇和海の食と多世代の交流 | 宇和海の食文化交流（仮） |
| `event-literature.png` | 松山のまち歩き、手帖、ことばの交換 | 俳句とまち歩き（仮） |
| `event-art.png` | 作品を介した鑑賞者の対話 | 表現の掲載例 |
| `event-pre2026.png` | 合唱・吹奏楽・舞踊の舞台 | プレイベントの概念イメージ |

7点はalpha.5でbuilt-in image_genを用いて新規生成した画像であり、alpha.6でも元画像・指示・配信版を保持する。
1536×1024pxの元画像を `design-lab/assets/art-masters/` に保存する。
投入した英語プロンプト全文、生成日時、元画像の寸法・SHA-256は `assets/event-image-prompts.json` に記録する。
配信版の寸法・容量・SHA-256は `assets/art-manifest.json` に記録する。
WebPへの変換は寸法変更と符号化だけであり、合成・加筆は行っていない。

7点を画像として確認し、人物の活動、舞台と観客の関係、構図の切り取り、文字・ロゴの混入を点検した。
実在の催し・出演者・会場・作品を撮影した記録ではないことを、画像と詳細ページに明示する。
生成画像は全6詳細、イベント一覧、関連文化、文化帖、および元v1の60イベントカードへ反映する。

旧白磁の接写と絵付けの画像も元画像・配信版とも保持する。
旧指示と素材の記録は `history/V2_ART_DIRECTION_ALPHA4.md` を参照する。
元v1の画像39点は変更せず、新しい配信用画像は別フォルダーへ出力する。

## alpha.6の実写記録と編集

主景は文化祭全体の生成イメージのまま、文化紹介には既存の実写記録を加える。
新居浜の太鼓祭り、伊予鉄道の俳句ポスト、内子座の客席、国立民族学博物館の牛鬼の4点を使用する。
元JPEG4点、縮小・WebP符号化した配信用12点を同梱する。
画面のキャプションで著作者、撮影時期、原写真、CC BY-SA条件、変更内容を示す。

文化の背景は各自治体の一次資料に基づく独自の説明である。
内子座は保存修理の長期休館中。牛鬼の写真は大阪の展示物であり、宇和島での祭りの開催写真ではない。
俳句ポストの写真は2008年の記録で、現在の車内設備を保証しない。
文化の記録と、本大会の催しの架空の掲載例を同一の開催情報として扱わない。

取材と素材の独自性を深める必要は残る。この版の調査を現地インタビューと称さない。
一次資料、写真の選定根拠、体験への接続はV2_CULTURAL_RESEARCH.md、個別の再利用条件はassets/CULTURAL_PHOTO_LICENSES.mdを参照する。
