# D2再設計の実装と検証

## 判断と変更範囲

2026-10-01の比較で、旧A・B案は「従来v1とそんなに変わらない」と評価された。
この評価を方向性の要件に対する不合格として記録し、旧A案への暫定推奨を撤回した。
v1の構成を維持する条件を見直し、掲載情報と必要な機能を保ちながら構成と体験を刷新する方針にした。
バージョンは2.0.0-alpha.3、状態はdesign-concept-resetである。

トップ2案と比較画面を作り直した。
新A案は「文化の群島」、新B案は「参加型ポスター」であり、両案は未選定である。
検索・詳細・資料・部品は前工程の試作を引き継ぎ、配色と資産を更新した。
下層の構成からの再設計、既存トップへの適用、115ページ展開は後続工程で行う。
v1-frozenと既存サイトのページ、元の画像、元のCSS・JavaScriptは変更していない。

## v1および旧案との対応

| 対象 | v1・旧A/B | 新A | 新B |
| --- | --- | --- | --- |
| 最初の画面 | 一つの主写真とコピー、または左右の写真・コピー | 複数の文化写真を群島として編集 | 画面を占める文字と3つの参加目的 |
| 写真 | 大会の雰囲気を伝える主な背景 | 文化を選ぶと主写真、説明、行き先が変わる | 参加目的を選ぶと写真、言葉、行き先が変わる |
| 読む順序 | 紹介、写真、カード一覧、参加、お知らせ | 文化の選択、暮らしと文化、文化別索引、参加、お知らせ | 参加目的の選択、考え方、参加方法の索引、包摂性、お知らせ |
| 検索への入口 | ボタンとカード | 文化別の選択からジャンル検索へ | 観るという目的からイベント検索へ |
| 実用情報 | メニュー、検索、支援、資料 | 常設の検索と重要情報、支援と資料 | 同じ目的を異なる画面構成で提供 |

この表は実装上の違いを説明するものであり、画面の独自性や受賞可能性の合格証拠ではない。
方向性の要件はPCとスマートフォンの画面比較で評価する。

## 操作の意味

新Aでは工芸・舞台・文学・食文化を選ぶ。
主写真、説明、ジャンル検索、掲載例のリンクが同じ選択に対応する。
新Bでは観る・つくる・ともにを選ぶ。
イベント検索、参加・募集、参加支援へ進むために、写真と言葉を切り替える。
選択をURLへ記録し、再読込や履歴移動でも同じ入口を復元する。
フォーカスを動かさずに選択状態を示し、更新を読み上げ用の領域へ通知する。

JavaScriptなしでも、新Aの4つの文化別リンク、新Bの3つの参加目的別リンクが残る。
写真が動かなくても、本文、検索、参加支援、資料へ進める。

## 確認できた結果

| 検査 | 結果 | 根拠 |
| --- | --- | --- |
| HTML構造・参照 | 7ページ PASS | design-lab/qa/static-checks.json |
| 色の組合せ | 31組 PASS、通常文字の最小比 5.701:1 | 同上 |
| 画像と書体のハッシュ | 24件 PASS | 同上 |
| 選択・検索・復元・メニュー・比較ファイルのロジック | 16ケース PASS | design-lab/qa/interaction-checks.json |
| A案の小画面向け初期素材 | 415,258 bytes | static-checks.json |
| B案の小画面向け初期素材 | 360,075 bytes | 同上 |
| 配置の参考画像 | PC幅・390px、10枚 | design-lab/qa/layout-references.json |

容量の条件は320〜390 CSS px、DPR 1、最初の画面の写真を480wで選ぶ場合である。
HTML、CSS、JavaScript、全書体を含み、下方の写真と、選択後に追加で読む写真は含まない。
実際の通信量、描画時間、操作遅延の測定ではない。
静的検査で画像2点の破損を検出し、画像をメモリー上で生成してからファイルを置換する方式へ修正した。
全24件のハッシュを再照合した。

操作の検査にはjsdomを使った。
文化と催しの対応、参加目的と案内先の対応、URL復元、フォーカスの維持、JavaScriptなしの入口を確認した。
実機のキー入力、読み上げ、表示速度を確認したという意味ではない。

## 画面と完成度の判定

WeasyPrintの画像を使い、配置の参考資料として文字の折返しと写真の関係を見直した。
この画像は実ブラウザーのスクリーンショットではない。
JavaScriptの選択部品は表示されず、CSSやSVGの処理にも実ブラウザーとの差がある。
