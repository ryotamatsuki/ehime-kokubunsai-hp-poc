# alpha.6の自己評価と改善記録

日付：2026年10月2日。対象：2.0.0-alpha.6。状態：cultural-editorial-review。
Design Brief、15事例のDesign Benchmark、100点のQuality Gateを参照し、書体・主景・読む順序・下層構成・素材と操作のつながりを改訂した。
総合点と完成判定は保留する。検査のPASSを受賞水準への到達と置き換えない。

## 指摘と改訂の関係

| 課題 | 改訂 | 確認できた範囲 |
| --- | --- | --- |
| 主画像が見え始める位置が遅い | PCは5:7の非対称構図で見出しと画像を同じ開始位置へ。小画面は主見出しの直後に画像 | 1440pxの静的参考で画像上端は約612pxから約217pxへ。実ブラウザーでは未確認 |
| 6催しを通過しないと文化紹介へ着かない | 文化の記録を主景の直後へ。全6件は小画像を添えた短い一覧にして文化紹介の後へ | DOMの順序、全6件の画像・日付・情報状態とリンクを確認 |
| 書体と文字組の印象が重い | 大きな章題をZen Maru Gothic Medium500、本文と操作をZen Kaku Gothic New400、英数字をManropeへ。強い詰めと太字の濫用を解消 | 本文PC20px・小画面18pxを維持。840日本語文字を収録。実機・拡大・代替書体は未確認 |
| 下層に同じテンプレートの印象が残る | 読む目的を9種類に分け、具体的な内容を先へ、背景・出典・関連案内を開閉できる補足へ | 元114ページの全10,514本文箇所を保持。目次から該当の開閉欄を開く操作も確認 |
| 愛媛の文化の素材と独自体験が必要 | 実写4点と自治体の一次資料から、年代・写真を見る問い・出典を一組にする。自分のことばを文化帖へ残す。文学は俳句ポストからかなの十七音とSVGへつなぐ | 4素材の著作者・日付・CC BY-SA、保存・削除・安全な入力・音数補助・書き出しを確認。新規の現地取材とインタビューは未実施 |
| ブラウザーでの操作・読みやすさ・性能の最終確認 | 許可されたブラウザーでローカルHTTPと共有HTMLへのアクセスを試行 | HTTPはERR_BLOCKED_BY_CLIENT、file URLはセキュリティ設定によって拒否。実表示と実測性能は未確認 |

文化祭全体の生成主景、全6催しの固有AI画像、元v1の全4仮イベントは維持する。
内子座の休館、古い俳句ポストの記録、牛鬼の写真が大阪の博物館の展示であることを明示する。
新しい文化紹介を本大会の開催情報として読ませない。

## 画面・書体・容量の改善

| 巡 | 発見 | 修正・再確認 |
| --- | --- | --- |
| 1 | 新しい主景・文化順を描画。狭い画面の長い催し名と文化選択操作に、本文6箇所・操作10箇所の画面外へのはみ出し | 折り返し、最小幅、項目内の見出しサイズを修正 |
| 2 | トップ4参考で本文・操作の画面外0 | 下層と文化体験を横断確認へ |
| 3 | 51参考で、320pxのことば入力と1250pxの文化帖保存操作に本文16箇所・操作10箇所のはみ出し | グリッドをminmax(0,1fr)へ、入力側の最小幅を解消、文化帖保存を一列へ。縦書きの列幅を明示 |
| 4 | 51参考で本文・操作の画面外0。ただしWeasyPrintによる分割書体の処理で、日本語字形の取り違えを発見 | 全分割ファイルの内部名を固有にする。WeasyPrintのUnicode範囲未対応には、同じ元書体の全文字サブセットを参考描画だけに使用 |
| 容量 | 追加書体とCSSで小画面向け500,000 bytesの予算を超過 | 太字の用途を整理し、実務の小見出しは本文書体へ。Unicode範囲を分割。使用しないCSSを整理し、操作に必要な文化データだけを配信 |
| 最終目視 | 境界検査では0だったが、文化の選択欄と入力欄の内側が窮屈だった | 選択欄を地域・地名・文化の三段の文字組へ、入力欄を自然な一列の配置へ。四つの文化と保存後の文化帖を含む87参考を確認 |

各巡は `design-lab/qa/cycle-alpha6-*/layout-references.json` に記録する。
最終巡の全参考画像を残す。中間巡は欠点を示す代表画像と計測を残し、未収録画像はoutputをnullとする。
字形が不正確な中間参考を、最終の読みやすさの根拠として使わない。
参考描画の補正は実サイトのHTML・CSSの変更ではなく、ブラウザー検証でもない。
保存後の文化帖3参考には、参照画像用に作った観察の入力例を使用する。実際の来場者の声ではない。

操作検査はjsdomでの状態・イベント・復元・安全な出力の確認である。
文化の選択、気づいたことの保存、保存失敗、削除後のフォーカス、かなの音数補助、SVG出力、開閉欄の目次、オフラインでの状態継続を追加した。
自由入力のスクリプト様文字列が確認用HTMLの構造を壊さないことも確認する。

容量は390/1440px・DPR1の概算で、HTML、CSS、共有スクリプト、該当する文字範囲の書体、代表画像を合計する。
表示する後続本文の書体も含むが、遅延画像、DPR2以上、通信ヘッダー、キャッシュ、読み込み時間は含まない。
全ページ同梱のreview.htmlは別に数える。
この計算をCore Web Vitalsや実際の入力遅延の測定として扱わない。

参考描画はWeasyPrint70とjsdomのDOMを使用する。
Unicode範囲の選択は全文字サブセットへ、aspect-ratioは寸法へ、display:contentsは参考DOMの組替えへ置き換える。
縦書き、フォーム、フォーカス、flexの実描画はブラウザーと異なるため、最終確認の対象として残す。

## 品質軸の判定

| 品質軸 | 今回の根拠 | 完成判定に残ること |
| --- | --- | --- |
| Concept & First Impression | 文化祭全体の主景と強い主見出し、主景直後の土地の文化 | 実画面、初見利用者の理解 |
| Originality & Cultural Identity | 実写記録・年代・出典、文化から自分のことばへつなぐ操作 | 新規の現地取材・専用素材、担い手の声、専門家の評価 |
| Typography | 本文サイズ維持、主見出しと実務見出しの分離、全文字収録 | 実ブラウザー、200%拡大、代替書体、実機 |
| Visual Composition & Art Direction | 5:7の主景、文化4章、9種の下層構成、短い催し一覧 | 実画面の細部とページ間のリズム、第三者評価 |
| Motion & Micro-interaction | 保存・入力・選択・任意の制作、低減設定の分岐 | 実表示の低減設定、応答時間 |
| Structure & Navigation | 114対応の比較、全案内の索引と検索、目次・関連文化 | 初見利用者によるタスク成功 |
| Mobile Experience | 320/390pxと中間幅の静的な構図・境界検査 | 実機、縦横切替、拡大、入力時の画面 |
| Accessibility | コントラスト、意味のあるHTML、キーボードの状態、通知とフォーカス | 実ブラウザー、読み上げ、手動監査 |
| Performance & Technical Craft | レスポンシブ画像、分割書体、容量予算、必要データのみ配信 | HTTPS配信での通信、LCP・INP・CLS、操作の実測 |
| Public-service Utility & Trust | 全本文と元催し保持、確認済みと架空の例、写真の文脈と出典 | 行政の内容・更新運用確認、利用者検証 |

総合点は算定しない。Accessibility・Performance・Public-service Utility & Trustの最終ハードゲートは保留する。
90点以上・全項目8点以上という完成条件は維持する。

## 今回の提出の扱い

公開資料と実写に基づく文化の編集、独自のことばの体験、書体・構図・下層の改訂を実装したalpha.6である。
実ブラウザーの確認と新規の現地取材が未完了のため、受賞水準の完成版とは自己認定しない。
2.0.0の完成判定とv2-frozenは保留する。
alpha.4・alpha.5の設計と自己レビューは `docs/history/` に保存する。
