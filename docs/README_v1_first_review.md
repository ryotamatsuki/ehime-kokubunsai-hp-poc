# 令和10年度 国民文化祭・全国障害者芸術・文化祭 愛媛大会（仮）
# 公式ホームページモック README

## 1. 概要

本リポジトリは、令和10年度に愛媛県で開催予定の「国民文化祭・全国障害者芸術・文化祭 愛媛大会（仮）」公式ホームページの静的HTMLモックです。

本モックは、実際の公開サイトではなく、ホームページ基本構成、情報設計、デザイン方針、主要ページの導線、アクセシビリティ対応、協賛募集ページ等の検討を行うためのプロトタイプです。

本モックでは、上司・庁内関係者・制作会社等に「完成イメージ」として提示しやすいよう、イベント検索、イベント詳細、募集、協賛、アクセシビリティ、観光・アクセス等の主要ページについて、実際のWeb画面に近い粒度で構成しています。

現時点で、大会正式名称、統一名称、会期、ロゴマーク、キャッチフレーズ、マスコットキャラクター、協賛制度、イベント内容等は未確定のため、各ページ内では「（仮）」「未定」「正式決定後掲載」等の表記を用いています。

---

## 2. 本モックの目的

本モックの目的は、以下のとおりです。

1. 愛媛県国民文化祭公式ホームページの全体構成を可視化する。
2. トップページ、大会概要、イベント情報、募集情報、協賛、観光、アクセス、アクセシビリティ等の主要導線を確認する。
3. 行政サイトとしての正確性・誠実性を保ちつつ、欧米的なモダンさ、余白、写真表現、文化的品格を備えたデザインの方向性を検討する。
4. 会期前、会期中、会期後のサイト運用イメージを整理する。
5. 制作会社、関係課、市町、実行委員会等との協議用たたき台として使用する。
6. 主要ページについて、実際の公開サイトに近い完成イメージを共有する。

## 3. 主要ページの作成方針

本モックでは、主要ページを単なる仕様説明ではなく、上司・庁内関係者が完成後の画面を具体的に想像できる粒度で作成しています。

### 3.1 重点的に具体化している主要ページ

重点的に画面イメージを具体化しているページは以下のとおりです。

```text
イベント検索：events/search.html
イベント詳細：events/detail.html
募集情報トップ：recruitment/index.html
出演・出品者募集：recruitment/performers.html
ボランティア募集：recruitment/volunteer.html
応援事業募集：recruitment/support-projects.html
協賛パートナー募集：sponsors/partner-recruitment.html
アクセシビリティ情報：accessibility/information-support.html
観光モデルコース：tourism/courses.html
鉄道アクセス：access/train.html
会場別アクセス：access/venues.html
共通スタイル：style.css
```

### 3.2 作成方針

- 「このページで確認できること」「正式公開時に近い内容イメージ」などのメタ説明を削減。
- 仮のイベント名、日時、会場、料金、申込、バリアフリー対応、問い合わせ先等を配置。
- 募集ページでは、募集対象、募集期間、応募方法、提出書類、審査・決定、FAQ等を具体化。
- 協賛ページでは、企業向けの文化パートナーシップ提案として、協賛の意義、メリット、メニュー、申込の流れを整理。
- アクセシビリティページでは、情報保障、イベント別対応、相談導線、やさしい日本語等をより具体的に配置。
- 観光・アクセスページでは、モデルコース、主要起点からのアクセス、会場別アクセスを画面として見せやすく整理。
- 既存のヘッダー、フッター、色、余白、カードUI等のデザインシステムは維持。

### 3.3 その他ファイルの扱い

本モックは、重点的に具体化した主要ページだけでなく、公式ホームページ全体を確認できる完全体一式です。

したがって、トップページ、その他下層ページ、画像、CSS、JavaScript、検索用データ、説明用HTML等も同梱されています。

## 4. デザインコンセプト

本モックは、従来型の行政ホームページに多い情報過多なデザインではなく、文化祭にふさわしいブランドサイトとして設計しています。

基本方針は以下のとおりです。

- 行政としての信頼性、正確性、公共性を担保する。
- ファーストビューでは、説明よりも世界観を優先する。
- 瀬戸内海、宇和海、石鎚山、四国遍路、お接待の心、柑橘、工芸、舞台芸術、障がい者芸術等の愛媛らしさを視覚的に表現する。
- 色数を絞り、深い藍色、生成り、柑橘色、金色を基調とする。
- バナーの乱立、過剰なPDFリンク、囲み枠の多用を避ける。
- 余白、写真、短いコピー、明確なCTAで視線誘導する。
- アクセシビリティとスマートフォンでの使いやすさを重視する。
- 上司や関係者に見せた際に、単なるページ一覧ではなく「完成後のサイト像」が伝わることを重視する。

## 5. モックの特徴

### 5.1 静的HTML構成

本モックは、HTML、CSS、JavaScriptで構成された静的サイトです。

サーバーサイド処理やデータベースは使用していません。  
そのため、`index.html` をブラウザで開くだけでも確認できます。

### 5.2 公式サイト全体を想定した多ページ構成

トップページだけでなく、以下のような公式サイトに必要な主要ページ群を含んでいます。

- 大会概要
- お知らせ
- イベント情報
- 募集情報
- 広報活動
- 協賛・応援企業
- 観光・周遊案内
- アクセス
- アクセシビリティ・バリアフリー情報
- 報道・メディア向け
- 実行委員会・会議資料
- 入札情報
- サイトポリシー
- 会期後アーカイブ

### 5.3 主要ページの完成イメージ化

本モックでは、特に次のページ群について、画面としての具体性を高めています。

- イベントを探すページ
- イベント詳細ページ
- 出演・出品者募集ページ
- ボランティア募集ページ
- 応援事業募集ページ
- 協賛パートナー募集ページ
- アクセシビリティ情報ページ
- 観光モデルコースページ
- アクセス案内ページ

これにより、関係者説明時に「どのような公式サイトになるのか」を具体的に示しやすくしています。

### 5.4 検索・絞り込みの簡易モック

`search-index.js` にサイト内検索用の仮データを持たせています。

また、一部イベントページでは、キーワード、市町、ジャンル等による簡易的な絞り込み表示を想定しています。

本番化時には、CMSやイベントデータベース等と連携した検索・絞り込み機能への置き換えが必要です。

### 5.5 アクセシビリティ対応の試作

以下のようなアクセシビリティ配慮を想定しています。

- スキップリンク
- 文字サイズ変更
- 高コントラスト表示
- キーボード操作
- 代替テキスト
- アクセシビリティ支援ツールページ
- やさしい日本語ページ
- イベント別バリアフリー対応情報
- 情報保障ページ
- PR動画の字幕・手話あり版の想定

## 7. ページカテゴリの概要

### 7.1 トップページ

`index.html`

大会全体の入口となるページです。  
愛媛大会（仮）の世界観、主要導線、重要なお知らせ、イベント、募集、協賛、観光、アクセシビリティへのリンクを配置しています。

### 7.2 共通機能

`common/`

サイト内検索、重要なお知らせ、アクセシビリティ支援ツール、言語切替、SNSリンク等を扱います。

### 7.3 大会概要

`about/`

大会の意義、基本方針、名称、キャッチフレーズ、ロゴ、マスコット、会期、国民文化祭とは何か、全国障害者芸術・文化祭とは何かを説明するページ群です。

未確定情報は、確定後差し替える前提で仮ページ化しています。

### 7.4 お知らせ

`news/`

重要なお知らせ、募集情報、報道発表、実行委員会からのお知らせ等を扱います。

会期中は、イベント変更、中止、交通規制、荒天対応等の即時情報発信にも利用する想定です。

### 7.5 イベント情報

`events/`

イベントカレンダー、イベント検索、市町別、ジャンル別、バリアフリー対応別、親子向け、無料イベント、予約が必要なイベント等の導線を配置しています。

本モックでは、特に `events/search.html` と `events/detail.html` を完成イメージに近づけています。

本番では、実施計画や各市町プログラムが確定した後、実データに差し替える必要があります。

### 7.6 募集情報

`recruitment/`

出演・出品者募集、ボランティア募集、応援事業募集、協賛企業募集、入札情報等をまとめます。

本モックでは、`recruitment/index.html`、`recruitment/performers.html`、`recruitment/volunteer.html`、`recruitment/support-projects.html` を重点的に作成・調整しています。

文化団体、個人、企業、事業者など、参加を希望する人の入口となるカテゴリです。

### 7.7 広報活動

`pr/`

PR動画、字幕・手話あり動画、広報大使、SNSキャンペーン、広報素材ダウンロード、市町・企業向け広報協力のお願い等を扱います。

### 7.8 協賛・応援企業

`sponsors/`

協賛パートナー募集、関心表明フォーム、協賛企業一覧、寄付企業一覧、協力企業一覧、協賛企業インタビュー等を扱います。

本モックでは、`sponsors/partner-recruitment.html` を、単なる募集要項ではなく、企業・団体に対して文化パートナーシップの価値を提示するページとして重点的に作成・調整しています。

### 7.9 観光・周遊案内

`tourism/`

県外来訪者や県内周遊者向けに、愛媛への旅、モデルコース、宿泊、食・土産・文化体験、市町観光リンク等を扱います。

本モックでは、`tourism/courses.html` を、文化祭イベントと観光資源を接続するページとして重点的に作成・調整しています。

### 7.10 アクセス

`access/`

飛行機、電車、車、フェリー、バス、会場別アクセス、バリアフリー交通情報を扱います。

本モックでは、`access/train.html` と `access/venues.html` を重点的に作成・調整しています。

松山空港、JR、伊予鉄、フェリー、島しょ部・南予方面などを想定した広域案内が必要です。

### 7.11 アクセシビリティ・バリアフリー情報

本モックでは、`accessibility/information-support.html` を重点的に作成・調整しています。

本サイトにおいて特に重要度の高いカテゴリです。

### 7.12 報道・メディア向け

プレスリリース、取材申込、写真・動画素材、ロゴ使用、報道問い合わせ等を扱います。

`policy/`

## 8. ローカルでの確認方法

### 8.1 最も簡単な確認方法

`index.html` をブラウザで直接開いてください。

```text
ehime-kokubunsai-hp/index.html
```

Google Chrome、Microsoft Edge、Safari等で確認できます。

### 8.2 ローカルサーバーで確認する方法

ブラウザで直接開く方法でも大半のページは確認できますが、検索や相対パスの確認を安定させたい場合は、ローカルサーバーで確認してください。

Pythonが使える環境では、以下のように実行できます。

```bash
cd ehime-kokubunsai-hp
python3 -m http.server 8000
```

その後、ブラウザで以下にアクセスします。

```text
http://localhost:8000/
```

Windows環境で `python3` が使えない場合は、以下のように実行できる場合があります。

```bash
python -m http.server 8000
```

または、VS CodeのLive Server拡張機能などを利用しても確認できます。

### 8.3 Python launcher が使えない場合

環境によっては、Python launcher がブロックされる場合があります。

その場合でも、HTMLは静的ファイルとして生成済みのため、以下の方法で確認できます。

1. `index.html` を直接ブラウザで開く。
2. VS CodeのLive Server等、Python以外の簡易サーバーを使う。
3. Webサーバー上にフォルダごと配置して確認する。

Pythonが使えない場合でも、既存HTML、CSS、JavaScriptの直接編集は可能です。

全体のデザインは主に以下のファイルで管理しています。

```text
style.css
```

色、余白、フォント、カード、ボタン、ヘッダー、レスポンシブ表示等はこのファイルで調整します。

### 10.3 動作を編集する場合

メニュー開閉、検索フォーム、カウントダウン、仮フォーム、イベント絞り込み等の動作は以下で管理しています。

```text
script.js
```

検索対象の仮データは以下で管理しています。

```text
search-index.js
```

### 10.4 画像を差し替える場合

画像素材は以下のフォルダに格納されています。

```text
assets/
```

画像を差し替える場合は、ファイル名を維持するか、HTML内の参照パスを修正してください。

## 11. 生成スクリプトについて

本モックには、HTML生成用のスクリプトが含まれています。

```text
generate_site.py
```

ただし、環境によってはPython launcherがブロックされる場合があります。  
その場合は、生成スクリプトを使わず、既存HTMLを直接編集してください。

再生成を行う場合は、既存HTMLの直接修正が上書きされる可能性があります。  
直接編集した内容を保持したい場合は、再生成前にバックアップを取ってください。

本モックでは主要ページを直接作成・調整しているため、安易に再生成すると、作成・調整済みページが初期状態に戻る可能性があります。

## 14. 注意事項

### 14.1 本モックは公式公開物ではない

本モックは検討用の試作品であり、公式公開サイトではありません。  
掲載されている文言、数値、制度、ページ名、問い合わせ先等は仮のものを含みます。

### 14.2 画像素材の扱い

`assets/` 配下の画像は、モック検討用の素材として扱ってください。  
本番公開時には、権利処理、肖像権、クレジット、利用許諾を確認する必要があります。

### 14.3 イベント情報の扱い

イベント名、開催日、会場、料金、バリアフリー対応、問い合わせ先等は、完成イメージ確認用の仮情報を含みます。

本番公開時には、実施計画、市町プログラム、実行委員会決定事項等に基づき、正式情報へ差し替えてください。

### 14.4 協賛情報の扱い

協賛区分、金額、特典、掲載順、ロゴ使用ルール等は、正式な協賛制度が決定するまで仮扱いです。

本番公開時には、実行委員会の募集要項、審査基準、掲載基準に合わせて修正してください。

### 14.5 アクセシビリティ

本モックではアクセシビリティ対応の方向性を示していますが、本番化にあたっては、JIS X 8341-3等の基準、県公式サイトのアクセシビリティ方針、実際の利用者ニーズを踏まえた検証が必要です。

### 14.6 PDF依存の抑制

本番サイトでは、PDFを掲載するだけでなく、主要情報をHTML本文としても掲載することが望ましいです。

特に、募集情報、イベント情報、アクセス、バリアフリー情報は、PDFを開かなくても概要が分かる構成にしてください。

## 18. まとめ

本モックは、令和10年度 国民文化祭・全国障害者芸術・文化祭 愛媛大会（仮）の公式ホームページについて、情報構造、デザイン方向性、主要導線、ページ群、アクセシビリティ、協賛導線を検討するための静的HTMLプロトタイプです。

本モックでは、特にイベント検索、イベント詳細、募集、協賛、アクセシビリティ、観光・アクセス等の主要ページを、上司・関係者に「完成イメージ」として見せやすい粒度へ作成・調整しています。

特に重視している点は、以下の5つです。

1. 行政としての正確性と信頼性
2. 文化祭にふさわしい上質でモダンなデザイン
3. 愛媛らしさの視覚的表現
4. イベント参加・協賛・ボランティア等への分かりやすい導線
5. 全国障害者芸術・文化祭との一体開催を踏まえたアクセシビリティ

本番化にあたっては、正式情報の確定後、仮文言、仮画像、仮リンク、仮フォーム、協賛制度、イベント情報等を順次差し替え、CMS・検索・フォーム・緊急情報更新等の運用機能を整備する必要があります。
