# alpha.5の自己評価と改善記録

日付は2026-10-01、対象は2.0.0-alpha.5、状態はfestival-content-reviewである。
GitHubのDesign Brief、Design Benchmark、Quality Gateを読み直し、文化祭の広がり、祝祭感、可読性、情報量の保持を改訂の中心に置いた。
alpha.4の「器の接写を大会全体の入口にする」判断は、文化祭の印象を狭めていた。
ユーザーのPCでの指摘により、本文の小ささ、v1イベントの置換、比較手段の不足も改訂対象とした。

## 改訂した画面と体験

主景を舞台・鑑賞・交流・制作を含む文化祭全体に改め、7点のAI画像を新規生成した。
工芸は4つの文化の入口の一つとして扱い、トップを独占させない。
すべての催しに個別画像を設け、一覧、詳細、文化の紹介、文化帖と、元v1の60イベントカードに反映した。
本文はPC20px、小画面18pxを基本にし、会期、催し名、料金、支援、入力と操作も拡大した。

元114サイトページの本文10,514箇所と、全4仮イベントの名称・日程・地域・料金・支援条件を保持した。
トップの元本文は、リンクした文化祭の全体案内へ再配置した。
元115HTMLのうち基本構成資料1件も同梱する。
127通常ルート・128確認用ページと、16分類の全体索引、全114案内のサイト内検索を生成した。
固定版161ファイルは元コミットのGit blobと一致し、v1-frozenを変更しない。
比較画面は114ページの対応を持ち、左右の移動、PC全幅、390px表示を扱う。

| 3 | 51参考画像。検索・詳細・協賛・観光・フォーム・全体索引を横断。文化帖の小画面で本文と削除位置が崩れる | 項目画像、本文、削除の配置を明示。新規文字11字を含む書体を再生成 |
| 4 | 51参考画像。文化帖の小画面で本文・操作の画面外が各4箇所残る | 画像追加で変わったカードの構成を再評価し、幅を明示 |
| 5 | 文化帖3参考画像。幅の明示だけでは静的描画の崩れが残る | 小画面は画像・本文・削除を自然な一列の構成に変更 |

各巡の計測は `design-lab/qa/cycle-alpha5-*/layout-references.json` に記録する。
最終画像は全件保持し、中間巡は欠点を示す代表画像と全計測を残す。
保持していない画像はoutputをnullとし、存在するように案内しない。

静的参考画像はWeasyPrint 70で、jsdomが更新したHTMLを描画した。
未対応の画像比率を描画用に解決しており、ネイティブのフォーム・flex・SVGの処理はブラウザーと異なる場合がある。

## 完成条件の扱い

実ブラウザーのローカルプレビューが `ERR_BLOCKED_BY_CLIENT` で拒否され、表示・操作の監査は完了できていない。
実機、200%拡大、読み上げ、実測性能、初見利用者と行政運用の確認も残る。
総合点は算定せず、Accessibility・Performance・Public-service utilityの最終ハードゲートは保留する。
90点以上・全項目8点以上という完成条件と、文化祭全体の固有性を求める目標は維持する。

今回の提出物は、指摘に沿って全掲載内容・画像・共通設計を改訂し、検証可能なv1比較と改善履歴を持つalpha.5である。
受賞水準の完成版として自己認定したり、v2-frozenを作成したりしない。
alpha.4の自己レビューは `history/V2_SELF_REVIEW_ALPHA4.md` に保持する。
