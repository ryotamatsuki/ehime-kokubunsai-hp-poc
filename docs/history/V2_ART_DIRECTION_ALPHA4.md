## 白磁と藍

白い器と藍の筆跡を、文化に触れる入口にする。
器の表面、手の動き、文字の余白、利用者が描く線を同じ画面の中で関連付ける。
文学は5・7・5の点、食文化は器と魚と海、表現は開かれた幾何学図形を使う。
これらの図形は編集上の比喩であり、実在の作品、地図、大会ロゴではない。

### 生成指示の内容：白磁と藍の接写

以下は投入した英語プロンプトの内容を保存するための日本語要約である。

```text
Use case: photorealistic-natural
Asset type: 愛媛の文化祭PoCの主画像
Primary request: 美術館の図録のような質感で、白磁と藍の絵付けを接写する。
Subject: 無銘の手仕事の浅い白磁の器。広い藍の筆跡と、不完全な弧。
Composition: 縦4:5の接写。器を大きく切り取り、左下に顔料と木の筆を置く。
Lighting: 自然な昼の光。温かい白の背景。釉薬の表面と顔料のたまりを見せる。
Constraints: 砥部焼に着想を得た新規の架空の器。特定の作品の複製にしない。
Avoid: 文字、ロゴ、架空の日本語、果物、人、過剰な装飾。
Disclosure: サイトではAI生成イメージと表示する。
```

### 生成指示の内容：絵付けをする手

以下も投入した英語プロンプトの内容の日本語要約である。

```text
Use case: photorealistic-natural
Asset type: 工芸の文化ページの編集画像
Primary request: 白磁の器に藍の顔料で絵付けする成人の手を、図録の写真として描く。
Subject: 自然な比率の2本の手。筆を正しく持ち、器を支える。
Composition: 横3:2。動作を中央に置き、小画面のトリミングにも残す。
Scene: 淡い作業場の昼の光。背景は焦点を外し、筆、手、釉薬の質感を見せる。
Constraints: 特定の作家や作品を識別できる内容にしない。
Avoid: 顔、文字、ロゴ、群衆、特定の展示作品。
Disclosure: サイトではAI生成イメージと表示する。
```

生成後に器の構図、顔料の質感、手と筆の形、文字やロゴが混入していないことを画像で確認した。
実在の砥部焼作家や工房を撮影した写真として扱わない。
公開版に進む前には、許諾を得た現地の作品・つくり手の撮影や取材で、この文化の固有性を深める必要がある。
