# v2.0 Design Upgrade Brief

## 1. Mission

v1の掲載情報と必要な機能を保ちながら、情報の並べ方、ナビゲーション、画面構成、体験をv2.0として全面的に再設計する。
v1の情報構成やトップのセクション順を維持することは要件にしない。
2026-10-01の方向比較で、旧A・B案はv1からの変化が小さく、刷新の要件を満たさないと指摘された。
配色や書体だけの変更でD2を完了扱いにしない。

品質目標は、Awwwards、The Webby Awards、FWAで評価されるトップクラスのデジタル体験をベンチマークとする。ただし「受賞できる」という自己認定は行わず、受賞作に見られる設計・表現・技術品質を具体的な品質基準として使用する。

## 2. Core design intent

目指すのは「派手な自治体サイト」ではない。

- 愛媛の文化・風土・人の営みが伝わる固有性
- 文化祭らしい期待感と祝祭性
- 行政公式サイトとしての信頼性、正確性、可読性
- 高齢者、障害者、子ども、県外来訪者を含む幅広い利用者への包摂性
- 写真・余白・タイポグラフィを主役にした編集的な上質さ
- 動きが意味を持ち、操作を邪魔しないインタラクション
- モバイルでも品質が落ちないレスポンシブ体験

を同時に成立させる。

## 3. Non-negotiable constraints

v2.0のデザイン改善によって、以下を犠牲にしてはならない。

1. 重要なお知らせへの即時到達性
2. イベント検索・募集・アクセス・問い合わせの実用性
3. キーボード操作、フォーカス表示、十分なコントラスト
4. `prefers-reduced-motion` 等によるモーション低減
5. 低帯域・一般的なスマートフォンでも利用可能な性能
6. 行政情報の誤読を招かない情報階層
7. v1の保存性。v1-frozenは変更しない。

## 4. Design principles

### 4.1 Editorial, not template-like
均一なカードの大量配置ではなく、雑誌・展覧会図録のように情報の重要度に応じてリズムを変える。

### 4.2 Place-specific, not generic Japan
「和風」「柑橘」「波」の記号的装飾だけに頼らず、愛媛固有の写真、地形、工芸、祭礼、瀬戸内の光、都市と地域の文化を素材として扱う。

### 4.3 Motion with purpose
スクロール演出、トランジション、ホバー、パララックスは、情報の理解、空間の連続性、文化的な余韻を補強する場合のみ採用する。

### 4.4 Typography as interface
見出し・本文・ラベル・数字・英字を体系化し、文字組そのものをデザインの核にする。読みやすさを優先し、装飾書体の濫用は避ける。

### 4.5 Accessibility is a quality signal
アクセシビリティを「デザイン制約」ではなく、完成度の一部として扱う。

## 5. Development stages

### D0 — v1 Freeze
完了。v1完全版を `v1-frozen` に固定。

### D1 — Benchmark & Direction
受賞サイトを横断研究し、v2の視覚言語、レイアウト、モーション、タイポグラフィ、ナビゲーション原則を決定する。

### D2 — Design System
色、タイポグラフィ、グリッド、余白、角丸、境界線、影、写真比率、モーション時間、イージング、ボタン、カード、ナビゲーション等のトークンを定義する。

### D3 — Homepage
トップページを最初の実証ページとして全面刷新する。ここでv2のコンセプトを確定する。

### D4 — Page Archetypes
115ページを一括改修せず、まず以下の代表型を完成させる。

- 大会紹介
- イベント一覧・検索
- イベント詳細
- 募集
- 協賛
- 観光・アクセス
- アクセシビリティ
- お知らせ
- 資料・行政情報

代表型で品質を確定後、同系統ページへ展開する。

### D5 — Motion & Interaction
ページ遷移、スクロール、ホバー、メニュー、フィルター、検索、画像表示等の動きを統一する。

### D6 — Mobile / Accessibility / Performance
モバイル実機相当幅、キーボード、reduced-motion、コントラスト、読字性、読み込み量を重点監査する。

### D7 — Self Review Loop
`V2_QUALITY_GATE.md` に基づき自己評価し、基準未達項目を修正する。1回の自己評価で終了しない。

### D8 — Freeze
全ゲートを通過した時点を v2.0 とし、`v2-frozen` を作成する。

## 6. Definition of done for v2.0

- 品質ゲート90/100以上
- 10評価項目すべて8/10以上
- Accessibility / Public-service utility / Performance のハードゲートをすべて通過
- 主要ページ型でPC・スマートフォン双方の完成度が揃っている
- モーションなしでも情報が欠落しない
- 115ページへの展開でデザインシステムが破綻していない
- v1との差分が意図的に説明できる



## 7. 現在の実装範囲

2.0.0-alpha.5では、文化祭全体を主景とする「愛媛の文化を、全国へ。」に改訂した。
舞台、作品、ことば、食、交流、制作を扱い、工芸は文化の一分野として配置する。
本文はPC20px、小画面18pxへ改訂し、全6件の催しに固有のAI生成画像を付けた。

v1の全114サイトページの本文を、新しい共通設計に移行した。
元のトップ本文は、トップからリンクした文化祭の全体案内へ再配置している。
全4件の仮イベントの名称・日程・地域・料金・支援条件も保持する。
元115HTMLのうち基本構成資料1件は資料ファイルとして同梱する。
127の通常ルート、128の確認用ページ、全114案内へのサイト内検索と目的別索引を生成する。
`V2_CONTENT_INVENTORY.json` に元ページと移行先を記録する。

`design-lab/compare.html` はv1固定版と今回のv2を同じページで比較する。
元の161ファイルは固定コミットのGit blobと一致し、v1-frozenは変更しない。
旧A/B案の選択を依頼する工程は終了している。

D6・D7の検査を継続し、完成基準と配点は変更しない。
確認方法と具体的な改善は `V2_SELF_REVIEW.md`、素材と生成指示は `V2_ART_DIRECTION.md` に記録する。
